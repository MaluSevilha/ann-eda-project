# Redes Neurais e Deep Learning

Portfólio da disciplina. Os projetos usam dados de programas de ensino superior
dos Estados Unidos para estimar a renda mediana quatro anos após a conclusão: o
primeiro explora e prepara os dados, e o segundo treina e avalia uma rede neural
de regressão.

- [Regressão com redes neurais — College Majors 2026](projects/regression/index.md)
